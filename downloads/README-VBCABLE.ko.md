# VB-CABLE 설치 및 라이선스

**PortableMixer.exe에 이 패키지가 이미 내장되어 있습니다. EXE 하나만 배포하면 됩니다.** 첫 실행 때 설치 안내에서 `예`를 누르면 공식 설치 창이 열립니다. 설치 창을 닫으면 VB-CABLE을 바로 비활성화하고 확인 결과를 표시한 뒤 앱을 종료합니다. 다음 실행에서 활성화됩니다. 아래 ZIP 설치 절차는 수동 설치가 필요한 경우에만 사용합니다.

`VBCABLE_Driver_Pack45.zip`은 [VB-Audio 공식 사이트](https://vb-audio.com/Cable/)에서 받은 수정하지 않은 원본입니다. Windows 10/11 x64용 카탈로그의 Microsoft 서명을 확인했습니다. 설치 파일을 실행하거나 현재 PC에 설치하지는 않았습니다.

1. ZIP을 폴더에 풉니다.
2. `VBCABLE_Setup_x64.exe`를 관리자 권한으로 실행하고 제조사 설치 화면에서 진행합니다.
3. 제조사 안내대로 재부팅합니다.
4. PortableMixer.exe를 실행합니다. Discord 입력은 **CABLE Output (VB-Audio Virtual Cable)**입니다.
5. Portable Mixer를 종료하면 장치가 비활성화되고 다음 실행 시 활성화됩니다. 아래 수동 ZIP 설치는 앱이 감시하지 않으므로 최초 앱 실행 전에는 장치가 활성 상태일 수 있습니다.

VB-CABLE은 **VB-Audio의 Donationware**이며 Portable Mixer의 MIT 라이선스 대상이 아닙니다. 유용하게 사용하면 [기부/라이선스 구매](https://shop.vb-audio.com/en/win-apps/11-vb-cable.html)를 해 주세요. 업무/기관 사용과 재배포는 [VB-Audio 라이선스 조건](https://vb-audio.com/Services/licensing.htm)에 따릅니다. 원본 저작권/안내를 유지하세요.

이 앱을 종료하면 같은 VB-CABLE을 이용하는 다른 앱도 연결이 끊깁니다. 기존 오디오 작업에 사용하는 CABLE이라면 먼저 이를 고려하세요. 일반 마이크, 스피커, 다른 가상 드라이버는 제어 대상이 아닙니다.

실제 장치 전환과 Discord 수신은 아직 미검증입니다. 앱과 감시 프로세스를 동시에 종료하거나 전원이 갑자기 끊기면 장치가 활성 상태로 남을 수 있습니다. 앱을 다시 실행하고 종료하거나 장치 관리자에서 수동 비활성화하세요.
