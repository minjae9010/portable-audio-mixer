# Windows x64 0.5.1 개발 빌드

시작 차단 수정: 메인 `믹스 시작/중지`, 마이크 선택 사용, 명확한 프로그램 캡처 상태를 추가했습니다. 같은 Pack45 어댑터의 표준 출력과 16채널 출력이 중복으로 판단되어 render ID가 비던 오류를 native topology connector 선택으로 수정했습니다. 회귀 테스트와 실제 PC의 VB-CABLE 송출 엔진 시작 검증(마이크 없이 무음)을 통과했습니다.

2026-10-24 로고 적용: 보라색·민트색 믹서 슬라이더 로고를 실행 파일, 창, 트레이 및 두 화면의 헤더에 적용했습니다. 16~256px 아이콘 9개를 내장했습니다. Release 빌드와 CTest 5개, Windows 리소스 로딩 검사를 통과했습니다. [로고 원본과 생성 프롬프트](../assets/README.md).

2026-10-24 송출 믹서 수정: 앱별 볼륨·음소거는 Windows 앱 설정을 변경하지 않고 캡처한 믹스 입력에만 적용합니다. 추가한 앱들을 개별 프로세스 루프백으로 캡처하고 마이크와 합산합니다. `믹스 듣기`는 가상 마이크로 보내는 최종 블록을 Windows 기본 스피커에도 보냅니다. 캡처 장치 선택은 제거했습니다. Release 빌드, CTest 5개, 실제 프로세스 캡처·송출용 음소거·Windows 세션 설정 불변 검사와 기본 스피커 재생 스모크 테스트를 통과했습니다. 최종 GUI 배치·VB-CABLE/Discord 수신 및 음질 청취는 실기 미검증입니다. [상세 안내](MIXER_UI.ko.md).

**배포 파일은 `downloads/PortableMixer.exe` 하나입니다.** 공식 VB-CABLE Pack45 전체가 내장되어 있습니다. 첫 실행 시 미설치 상태라면 동의를 받아 공식 설치 프로그램을 엽니다. 설치 창 종료 직후 장치를 비활성화하고 결과를 확인한 뒤 앱을 종료합니다. 다음 실행 때 활성화합니다. 설치 후 재부팅이 필요할 수 있습니다.

현재 앱은 기존 Microsoft 서명 **VB-CABLE Pack45**를 사용합니다. 자체 드라이버 서명/테스트 모드는 필요하지 않습니다.

- `downloads/PortableMixer.exe`: 관리자 권한으로 실행하는 믹서 및 장치 수명 감시 프로그램.
- `downloads/VBCABLE_Driver_Pack45.zip`: 재현 빌드용 원본 패키지. 최종 사용자에게 별도로 전달할 필요 없음.
- `downloads/README-VBCABLE.ko.md`: 설치 및 VB-Audio Donationware 고지.
- `downloads/driver/`: 이전 0.3 서명 전 드라이버 실험 패키지. 현재 앱에서는 사용하지 않음.

빌드와 코어 테스트, 장치 수명 모의 테스트 9개, EXE 내장 파일 31개 원본 해시 검사를 통과했습니다. 내장 설치 프로그램의 실제 실행은 아직 확인하지 않았습니다. **실제 VB-CABLE 설치, 장치 활성/비활성 전환 및 Discord 수신은 미검증입니다.**
